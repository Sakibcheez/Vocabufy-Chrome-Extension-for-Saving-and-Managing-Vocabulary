# Vocabufy Privacy Notice

Vocabufy version 1.0.0 stores saved vocabulary, source-page details, captured sentence context, personal notes, definitions, favorites, settings, and encounter counts locally in the user's Chrome extension storage.

Vocabufy does not transmit data to its developer or any third party. It contains no analytics, advertisements, tracking code, account system, remote service, or external API. Network requests are not required for the extension's features.

The extension runs a content script on webpages so it can detect text selected by the user and display the **Add to my vocab** control. A page's selected term, nearby text context, title, and URL are stored only when the user deliberately activates that control or the corresponding context-menu command.

Users can view, edit, export, import, or delete stored vocabulary from the full vocabulary page. They can also disable the selection control, context-menu item, or success notifications. Uninstalling Vocabufy normally removes its Chrome-managed local storage.

Last updated: September 2, 2026.
